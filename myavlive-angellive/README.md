# Myavlive Angel Live 插件

将 `https://zh.myavlive.com/` 的公开直播接入 Angel Live。

## 功能

- 女主播、情侣、男主播、跨性别及常用标签分类
- 当前在线公开主播列表、搜索、详情和分享链接解析
- 多画质 HLS 播放
- 自动隐藏门票场、组秀、私密秀和其他需要付费的场次

## 安装

添加以下订阅源后安装，或直接导入同目录下的 `myavlive-angellive-1.0.0.zip`：

`https://raw.githubusercontent.com/bbnotcode/ph_js/refs/heads/codex/myavlive-angellive/myavlive-angellive/source-index.json`

Myavlive 与 Stripchat 使用同一套直播基础设施，HLS 清单采用 Mouflon v2。插件复用现有的云端清单解密服务；媒体分片由播放器直接连接官方 CDN，视频流量不经过该服务。

仅限年满 18 岁且符合所在地法律的用户使用。
